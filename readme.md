# 🎬 StarFetch
## A Full-Stack Blazor WebAssembly Cinema App  
*A production-ready movie discovery platform showcasing modern .NET development expertise*

Built with **.NET 8 Blazor WebAssembly**, StarFetch demonstrates my proficiency in creating responsive, interactive single-page applications that rival traditional JavaScript frameworks.

---

## 🏗️ Architecture & Design
- Clean service-layer architecture with dependency injection  
- RESTful API integration (The Movie Database API)  
- Browser `localStorage` persistence via JavaScript interop  
- Component-based UI with reusable Razor components  

---

## 💻 Technical Implementation
- **Backend:** C#, async/await patterns, LINQ, HTTP client configuration  
- **Frontend:** Blazor components, Bootstrap 5, responsive CSS Grid/Flexbox  
- **State Management:** LocalStorage service abstraction, favorites management  
- **Advanced Features:**  
  - Custom game engine with weighted randomization algorithms  
  - Real-time scoring system  
  - CSS-based tile reveal animations  

---

## 🎮 Featured Innovation: *Mosaic Movie Mania* Game
An interactive movie trivia game featuring:  
- Algorithmic tile-reveal mechanics using `PeriodicTimer`  
- Weighted movie selection (user favorites + trending titles)  
- Progressive scoring system with **10 Hollywood-themed rank tiers**  
- Accessibility-first design (`prefers-reduced-motion` support)
